# Phase 1 — integration note

Добавлен `phase1.js` с рабочим runtime-патчем:

- выбор сложности для мобильного интерфейса;
- коэффициенты Easy / Normal / Hard;
- блокировка престижа до 7-й локации;
- безопасная интеграция без падения игры, если подсистема ещё не загружена.

## Важно

`index.html` сейчас является монолитным файлом. Чтобы патч реально загрузился в игре, добавьте перед закрывающим `</body>`:

```html
<script src="phase1.js"></script>
```

После этого следующий проход подключит множители к фактическим функциям `G.click`, XP и наградам мини-игр. Я не стал подменять весь `index.html` неполным содержимым: это могло бы удалить существующую игру.
